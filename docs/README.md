## Ключевые принципы

### 1. Единообразие
Все диалоги следуют одинаковому паттерну:
- Управление состоянием через `useState`
- Блокировка прокрутки через `useEffect`
- Рендеринг через `createPortal`
- Интеграция с `react-hook-form`

### 2. Адаптивность
- Адаптивные размеры диалогов
- Поддержка мобильных устройств
- Правильное позиционирование

### 3. Доступность
- Блокировка фоновой прокрутки
- Семантически правильная разметка
- Понятная навигация

### 4. Производительность
- Условный рендеринг через Portal
- Оптимизированные CSS классы
- Минимальные перерендеры

## Технологический стек

- **React 18+** - основной фреймворк
- **Next.js** - Server Actions для серверной логики
- **react-hook-form** - управление формами
- **Tailwind CSS** - стилизация
- **html2pdf.js** - генерация PDF (в некоторых диалогах)

## Вопросы и поддержка

Если у вас есть вопросы по работе с диалогами:

1. Сначала изучите документацию выше
2. Посмотрите на существующие реализации в коде
3. Попробуйте адаптировать пример из `ExampleDialog.jsx`

## Внесение изменений

При добавлении новых диалогов:

1. Следуйте установленным паттернам
2. Используйте те же CSS классы для консистентности
3. Обновляйте документацию при необходимости
4. Тестируйте на разных размерах экрана
